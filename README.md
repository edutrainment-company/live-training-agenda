# Interaktive Trainings-Agenda

Dieses Paket ist bereits als statische Website gebaut.

Für GitHub Pages: Den Ordner `docs` in ein leeres Repository hochladen. Anschließend in GitHub unter **Settings → Pages** bei **Build and deployment** die Option **Deploy from a branch** wählen; danach **main** und den Ordner **/docs** auswählen und speichern.
